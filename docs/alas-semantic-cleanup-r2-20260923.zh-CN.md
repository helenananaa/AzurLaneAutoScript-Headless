# 第二轮语义适配清理（2026-09-23）

本轮在前一轮冻结帧缓存基础上继续清理，保留已有工作区改动，没有修改 ALAS 状态机、补丁系列或支持等级。

## 实现

### 输入准备复用

Session 通用点击入口取得的新帧，可以供该次调用内首次 `_fresh_input_oracle()` 使用，避免内层立即再取同一用途的帧。复用前调用原有 `borrow(frame_id, require_fresh=True)`；过期、失效、代次被刷新或运行时改变时，仍走正常重新获取流程。复用机会只消费一次，并在点击返回或异常时清理，不跨动作保存。

没有把所有 `refresh_frame()` 合并：动作后观察、跨等待和各任务主动请求的新观察仍然保留。真实输入仍经过前台/PID、时效、目标、遮挡及后置条件边界。测试覆盖正常路径一次获取、过期/失效后两次获取、调用结束后必须再次获取；未声称已测出真实动作的加速比。

### 直接解析冻结投影

帧 reader 直接提供已有不可变 Mapping/tuple 投影。基础解析器接受 JSON 容器及对应的不可变内部容器，保留原有身份、字段、数值、完整性和歧义验证。解析后的 `snapshot` 和 `raw` 直接引用冻结投影，因此删除 `_thaw` 及解析后的第二次递归冻结。

完整 UI、部分 Toggle 和文本读取继续隔离缓存。地图、宿舍物理、登录、退役和任务隔离回归包含在本次测试中。

商店壳身份是纯帧内判断，单独按帧缓存。没有缓存带任务上下文和动作授权的整个 `appear()`。

### 删除跨任务探测与修复错误阻断

登录上下文不再执行科研进度提示和通用战役页面判定；它们原本抢在登录自身判断之前执行，没有为登录分支提供所需信息。原登录 facade 的五项失败直接通过生产代码隔离修复，未放宽这些测试的结果或调用序列断言。

强化后保留装备的确认动作 `enhancement/equipment/preserve/confirm` 已由专用路径验证完整提示文本、唯一按钮及 top raycast，但此前仍被它自身的 Msgbox 通用遮挡规则拒绝。现在仅把这一明确动作加入该 Msgbox 的允许目标，与现有退役保留装备动作一致。加载遮挡、错误文本、缺失 top raycast 和重复目标测试均拒绝输入；没有允许通用未知确认。

## 原有 15 项失败的处理

- 登录 facade 五项：消除上述不相关探测，原断言不变。
- 战役/大世界/演习四项：补齐测试替身的 blocker 端口，默认无 blocker，测试可显式设置。
- Research 页面一项：成功场景提供实际需要的五张卡片；新增空卡片集仍不能认作完整页面的断言。
- META 会话一项：补齐输入帧刷新替身，并断言刷新被调用。
- 源码 inventory 一项：验证当前规范补丁的文件集合及当前 manifest 字节哈希，删除把历史文件数和历史哈希硬编码为永久要求的断言。补丁系列成员哈希校验仍保持不变并通过。
- 战役难度一项：按实际页面结构判断，测试同时覆盖未知页面拒绝；不再要求类似活动的 stage 名称否定已知章节页面结构。
- 预战斗返回一项：成功夹具提供 top raycast，并新增 raycast 未知时拒绝且不增加输入的断言。
- 强化装备一项：成功夹具提供必要 top raycast，另修复上述真实的 Msgbox 自身阻断；补充四种不安全情况的零输入覆盖。
