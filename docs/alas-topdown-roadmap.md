# ALAS 自上而下适配路线

## 目标

按 ALAS 侧栏顺序交付实际可运行的任务。保留 ALAS 原有调度、状态机、
重试和停止条件，只替换截图、OCR 和最终输入接口。

现有 G36 深度验证保留为技术资产，但不再作为其他任务开始前的阻塞项。

## 交付顺序

1. **Alas**：启动、配置、调度、状态和日志。
2. **出击**：普通主线的选关、舰队、出击、地图、战斗、结算、重复和停止。
3. **活动**：复用出击框架，补活动入口和关卡差异。
4. **活动每日**：A/B/C/D/SP 和共斗每日。
5. **收获**：石油、物资和经验书。
6. **每日任务**：
   - 每日任务；
   - 困难图；
   - 演习；
   - 通用商店；
   - 其他商店；
   - 开发船坞；
   - 每日抽卡；
   - 白嫖奖励；
   - 小游戏；
   - 宿舍计划。
7. **大世界**。
8. **工具**。

## 当前起点

- 语义观察、受控点击、ALAS patch series 和默认失败关闭机制已经存在。
- 普通主线已走到原始 ALAS `_goto()` 的最终格子点击边界，但完整真实战斗闭环
  尚未作为产品功能交付。
- 任务、委托、战术、科研、宿舍和建造已有局部适配代码；它们继续复用，等排到
  对应侧栏任务时再补成完整入口，不再横向扩展零散切片。
- 未完成的 G36 I03/H06c 工作保存在本地分支
  `codex/archive-alas-g36-wip-20260812`，不进入当前产品主线。

## 单项完成标准

一个侧栏任务只需同时满足：

1. 能由 ALAS 原任务入口和调度器启动；
2. 正常路径不读取真实 framebuffer，不回退旧坐标；
3. 在指定游戏版本和运行后端完成一次真实闭环；
4. 未识别页面、过期状态或目标歧义时停止；
5. 保留少量关键回归测试和一份简短结果记录。

普通功能不再新增独立的 gate 编号、离线篡改矩阵或大规模证据框架。消费钻石、
退役、购买、抽卡等不可逆或高价值操作可以单独增加确认和额度限制。

## 当前工作项：出击

按以下顺序完成普通主线，不并行展开其他菜单：

1. 从 ALAS 配置进入一个指定已解锁关卡；
2. 使用现有舰队并开始出击；
3. 让原始 ALAS 完成地图决策和移动；
4. 让原始 ALAS 完成战斗、结算和地图更新；
5. 完成有限次数重复以及油量、心情、次数等停止条件；
6. 用一次真实运行和必要回归确认后，转入“活动”。
