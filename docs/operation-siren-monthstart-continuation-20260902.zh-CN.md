# 月初开荒续跑与恢复修复（2026-09-02）

本轮接续[首轮月初适配](operation-siren-monthstart-20260902.zh-CN.md)，从正常配置 `monthstart` 的 `LastZone=24` 按原 ALAS 顺序推进。独立取样配置的 33 区不混入正常断点。

## 本轮修复

- 大地图仍被 `Loading(Clone)` 遮挡时不报告就绪；选区、取消选中和拖动在实际输入前检查当前阻挡状态。没有改变坐标模型或使用像素兜底。
- 游戏实际使用 `Msgbox/window` 的扫描确认弹窗。旧识别让原 `order_execute` 在处理确认前再次点击下层扫描按钮。现在仅在大世界指令面板所属的确认弹窗存在时，将扫描、潜艇和返回观察为不可操作；输入后等待该类确认出现，未出现则停止该动作。确认点击继续由原 ALAS 处理。
- 启动时残留指令面板改为调用原 `order_quit()` 收尾，避免一次返回点击被过渡状态吞掉后一直等待。
- 恢复到当前海域时，如果启动自律刚清理完该海域，先调用原 `ensure_no_map_event()`，再检查大地图海域类型。只有原流程确认安全后才保存游标。

改动集中在语义观察/输入边界和原恢复函数的接入，没有增加第二套开荒状态机。没有放宽前台/PID、generation、唯一目标、阻挡或输入后置条件。
