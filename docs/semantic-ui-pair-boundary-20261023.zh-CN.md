# 公共 UI 配对读取边界（2026-10-23）

`CoreOracle.read_ui_snapshot()` 现在先取得 UI 数据，再完成原有的前台检查。
这使默认的 state → UI 调用保持相邻，避免慢 ADB 前台查询被夹在两个端点之间，
人为制造 generation 差。本次没有增加调用、等待或兼容性门禁。

原来的顺序也不能发现 UI 请求期间发生的 Activity 切换；现在结束检查会拒绝这种
切换。包、PID、协议、freshness、generation、字段完整性和输入前的独立检查保留。
在非游戏前台取得的数据仅是只读响应，不会被接纳为可输入状态。

此修复位于公共 observer 边界，AVD 与 Redroid 共用；没有按模拟器类型分叉，
没有修改 ALAS 任务状态机、截图刷新语义或像素回退策略。已有需要专门配对/闭合
检查的端口保留其职责，本次没有再给每个任务加同类补丁。

新增测试使用真实奖励摘要调用路径，覆盖慢前台查询、请求中 Activity 切换、
真实 generation 差，以及无害附加字段和文字顺序变化。修复前该集合为
3 failed / 4 passed，修复后通过；拒绝场景均无输入。

相关 observer/字段隔离/会话/输入后前台检查集合为 **739 passed**。
随后原满仓恢复、装备保留、调度和重启契约的聚焦集合为 **90 passed**；
两组有重叠，不相加为唯一用例数。原始 XML 留在平台工作树
`artifacts/continuity-20261023/`。没有改动 ALAS patch series 或提升支持台账。

离线通过不证明自然满仓后的单进程连续恢复。实机强化与调度的范围另见平台本轮
记录，不将组件成功拼成完整 Main 证明。
