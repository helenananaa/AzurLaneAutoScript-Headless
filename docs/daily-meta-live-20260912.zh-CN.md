## 修复

1. 每日关卡原先导出上边缘 pivot，ADB 整数化后可能落到按钮外。观察器现在在可见按钮矩形内部取整数点，并让 Unity EventSystem 验证该点。实际第二档成功进入战前，第一档成功快速执行。
2. 每日页面作为奖励弹窗的下层不再阻止奖励关闭；`DAILY_ENTER_CHECK` 在奖励可关闭时为 false，让原生循环处理领奖。Daily 奖励点击归 Daily 上下文，不再落入 Mission。
3. 原生 META run 在语义模式确认已处于支援列表时直接进入已有支援逻辑，避免通用页面导航循环。
4. META 支援的实际战前开始操作消耗 `meta.assist` grant；已发出的开始回执在 20 秒过渡期内复用，避免重复输入。后续确认弹窗不会再次消费同一启动额度。个人信标路径保持原行为。
5. 旧战果按钮失去顶层命中后，仅在新鲜语义帧证明支援列表已恢复时结束战斗上下文；不点击旧按钮，不放宽命中要求。
6. 候选切换前刷新输入帧并再次核对候选身份；仅对按钮/文本代次不一致的观察做最多五次重读，保持原代次约束和其他错误。
