# ALAS 全功能当前验证清单（2026-10-25）

当前可用范围明显大于单一刷图，但**全功能长期无人值守稳定性尚未验证**。
以下覆盖全部 60 个配置面板及另 5 个源码入口；共享配置不是独立任务，空条件退出
不是战斗或资源事务成功。支持等级仍以 `integration/alas/support-matrix-ledger.json`
为准，本表不提升等级。详细失败、修复及收据关联见
[全功能实测记录](alas-full-feature-live-20261024.zh-CN.md)。

本次长跑经历多次真实缺口和有证据的修复，不能拼接成一段无故障运行。最后一段
CL1 已按原调度处理奖励并让出执行权，科研自然到期接手成功；随后主机关机中断。
只有这些具体结果可确认，没有通宵稳定的证据。强化和退役均按用户要求拆解装备。

`uncensored-r1`：原任务安装 47 字节的本地化文件，通过自身远端 SHA-256 校验，

验收脚本误将内存 LF 文本的哈希与实际 Windows CRLF 文件比较，原收据保留
`passed=false`。已修正验收逻辑；更正评估使用 `adb exec-out` 读取精确字节，
确认本地与设备文件逐字节一致、内容正确，零输入复核新 PID 5805、状态/UI
代次 2460、精确前台和主页。未重复安装或重启来覆盖原失败收据。

安装前的旧文件读取采用 `adb shell cat`，可能包含终端换行转换，只保留其原始
返回值，不把它当作字节精确备份；后续采集已改用 `exec-out`。本结果仅覆盖原
本地化文件路径，不包含远端仓库同步，也未用 ANGLE NULL 黑屏宣称美术效果通过。
